# Cybersecurity Password Manager (Java)

A simple console-based **Cybersecurity Password Manager** developed using Java and Object-Oriented Programming (OOP).

The application allows users to store and manage basic account credentials through a menu-driven interface.

> **Note:** This is an educational project. Passwords are stored as plain text and should not be used for storing real credentials.

## Features

- Add password entries
- View password entries
- Search entries by ID
- Update credentials
- Delete entries
- Menu-driven interface
- ArrayList-based storage

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner
